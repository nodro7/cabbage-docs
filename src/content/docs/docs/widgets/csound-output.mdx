`csoundOutput` creates a read-only text area that displays Csound's console messages inside the instrument. It is most useful when developing plugins, where the Csound console is not readily available: anything written with `printf`, `prints`, or similar opcodes is appended to the widget as it is produced.

:::note
Only the first `csoundOutput` widget in an interface receives the console text, so use one output widget per instrument.

## Csound Usage

Console messages are collected by the Cabbage backend and appended to the output widget. Any of Csound's printing opcodes will appear there:

```csound
printf("Frequency: %.2f Hz\n", 1, frequency)
prints("Instrument started\n")
```

To print only when something happens, gate the message with a channel trigger:

```csound
trigger:CabbageNumTrig = cabbageGetValue("printMessage")
if trigger.trig == 1 then
    printf("Button pressed at %.2f seconds\n", timeinsts())
endif
```

The widget is display-only and does not send values to Csound. Messages accumulate while the instrument is running.
