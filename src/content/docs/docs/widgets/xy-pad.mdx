`xyPad` creates a 2-dimensional X-Y pad controller that allows simultaneous control of two parameters. A draggable ball represents the current position, with independent channels for X and Y axes.

## Csound Usage

The `xyPad` returns the ball position on two independent channels, one for each axis. Read both at k-rate with `cabbageGetValue`:

```csound
kBW:k = cabbageGetValue("bandwidth")
kCutoff:k = cabbageGetValue("cutoff")
aOut:a butterbp aSrc, kCutoff, kBW
```
