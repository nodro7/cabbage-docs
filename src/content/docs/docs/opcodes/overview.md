Cabbage ships with a number of opcodes that provide an interface to each widget's underlying JSON object. Any property of a widget's `props` member can be accessed or modified using the `cabbageGet`/`cabbageSet` opcodes. A widget's value can be queried and set using the `cabbageGetValue` and `cabbageSetValue` opcodes. A number of utility opcodes are also included. Details of all opcodes can be found in the following pages.
